# Source data (not committed)

Download the official `module17_starter.zip` from UC Berkeley Assignment 17.1. Extract `data/bank-additional-full.csv` here, or put the original ZIP in `data/`, or set environment variable `UC_BANK_DATA_PATH` to the CSV or ZIP location.

The UCI bank marketing dataset is described by Moro, Cortez & Rita (2014), *Decision Support Systems* 62, 22–31; https://doi.org/10.1016/j.dss.2014.03.001. Full data comprise 41,188 observations, 20 predictors and target `y`. The raw CSV is intentionally excluded from the public repository.
